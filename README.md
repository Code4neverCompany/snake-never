# 🐍 Snake Never

> The Ultimate Snake Game Experience - 4neverCompany Edition

![Snake Never Logo](/public/logo.png)

## Features

- **Epic Synthwave Music** - Background music loop generated with AI
- **Glowing Visuals** - Gold and Cyan neon aesthetic
- **Smooth Animations** - 60fps with Framer Motion
- **Sound Effects** - Collect food, level up, game over sounds
- **Responsive Design** - Works on desktop and mobile
- **High Score Tracking** - Saved locally

## Controls

- **WASD / Arrow Keys** - Move snake
- **ESC / P** - Pause game
- **Touch Swipe** - Mobile controls

## Tech Stack

- React 18
- Vite 5
- Tailwind CSS 3
- Framer Motion 10

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build for Production

```bash
npm run build
npm run preview
```
